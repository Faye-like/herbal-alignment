项目介绍

年轻人养生现状 × 科普资源基层治理

一、我们解决什么问题

当下年轻人「养生意识觉醒」却「养生信息混乱」：一边熬夜一边保温杯泡枸杞， 一边跟风网络偏方一边被「酸碱体质」「排毒养颜」等谣言误导。权威、通俗、可执行的健康科普， 与年轻人的实际困扰之间缺少精准的匹配通道。

本项目通过一键点选养生关注点 → 标签规则匹配 → 个性化推荐科普资源与病症调理方案， 把优质科普资源与有科学依据的调理方式精准送到年轻人手里，同时为基层健康管理员提供资源管理与数据统计看板， 让科普资源在基层「看得见、用得上、可评估」。

二、核心机制：标签匹配

每条科普资源都被打上多维度标签：主题标签、适配困扰类型。 用户在前台一键点选养生关注点后，系统解析出用户的标签集合，并按标签重合度排序推荐：

  • 资源得分 = 适配困扰命中（高权重）+ 主题标签重合；
  • 示例：用户点选「睡眠差、焦虑」→ 优先推荐带「睡眠、作息、情绪」标签的科普文章。

病症调理模块则按「饮食 / 作息 / 运动 / 情绪 / 日常护理」分类，给出整理自权威机构 公开指南的具体做法与参考依据。

三、系统构成

A

用户前台

面向年轻人的落地页（一键点选关注点）、《青年养生知识手册》、病症调理、健康数据、打卡与查阅（含每日 / 每周计划与打卡）

B

管理后台

科普资源管理、数据统计看板

C

后端服务

RESTful API、标签匹配算法、SQLite 数据存储

四、技术栈

前端：原生 HTML + CSS + JavaScript（多页面）；后端：Python Flask + SQLite； 图表：ECharts。整体轻量、免安装数据库服务，便于比赛演示与打包部署。
